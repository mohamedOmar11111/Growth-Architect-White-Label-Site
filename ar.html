01 / ORIGIN

هذا ليس إطار عمل نظريًا. هذا سجلّ معركة، بعد تجريده من بيانات العملاء.

بناه المشغّل الذي حوّل حسابًا إعلانيًا حقيقيًا من عجز شهري قدره 70,000 SAR إلى +1,000,000 SAR صافي ربح خلال 12 شهرًا. «ذا فاوندري» هي المنظومة الفعلية وراء تلك النتيجة — مجرّدة من بيانات العملاء، ومغلّفة لتشغّلها وكالتك. التسويق ليس سحرًا. التسويق هندسة.

02 / THE SYSTEM

نواة واحدة. عملاء بلا حدود. صفر ارتهان لمزوّد.

SYS.01

متعددة العملاء من اليوم الأول

بيانات اعتماد كل عميل واستراتيجيته وتاريخه تعيش في مجلد معزول خاص به. لا احتمال لتسرّب بيانات عميل إلى تشغيل عميل آخر. ملف .env مستقل لكل عميل، ومستثنى من Git تلقائيًا.

SYS.02

غير مرهونة لمزوّد ذكاء اصطناعي واحد

Claude Code أو Cursor أو ChatGPT أو مفتاح API خام من Anthropic/OpenAI/Gemini دون أي وسيط — المسارات الأربعة جاهزة وموثّقة. بدّل وقتما شئت.

SYS.03

أتمتة حقيقية في الأساس

محرّك Python يدير الحالة والجدولة وسحب بيانات إعلانات Google الحيّة وتنبيهات Telegram. طبقة الذكاء الاصطناعي تتولى أعمال التقدير فقط. ما هو حتمي يبقى حتميًا.

SYS.04

لا شيء يخرج دون مراجعة

مبدأ الصانع/المراجع مدمج في عقد كل حلقة. المسوّدات تُكتب — ولا شيء يُرسل أو يُنشر أو يُعتمد تلقائيًا. أنت من يوافق على كل ما هو حقيقي.

SYS.05

أكثر من 60 تعريف وكيل

تسويق، هندسة، تصميم، منتج، اختبار، ودعم. فرقة تواصل اجتماعي كاملة: استراتيجي عابر للمنصات مع متخصصين لكل من X ولينكدإن وإنستغرام وتيك توك وريديت.

SYS.06

حزمة الذكاء [PREMIUM]

«برومبت ماستر» (37 نمطًا قاتلًا لهدر الرصيد)، مُراجِع «جرِل مي» العدائي، محرّك «هيومانايزر» ضد ركاكة الذكاء الاصطناعي، ومعيار «كيفمان» للتواصل عالي الكفاءة.

03 / THE ENGINE

سبع حلقات. ستٌّ تعمل اليوم.

LOOP.AD-INTEL

استخبارات الإعلانات

مراقبة حيّة لإعلانات Google، تنبيهات احتراق الميزانية والإنفاق الصفري، وتسليم زوايا الإعلانات الرابحة إلى محرّك المحتوى تلقائيًا — بلا تكرار وباختبارات انحدار.

LOOP.META-ADS

إعلانات ميتا

نمط المراقبة والتنبيه والتسليم ذاته، لإعلانات ميتا (فيسبوك/إنستغرام).

LOOP.CONTENT

محرّك المحتوى

يحوّل نتائج استخبارات الإعلانات إلى مسوّدات موجزات محتوى، مؤسسة على قواعد صوت العلامة في ملف STRATEGY.md الخاص بكل عميل.

LOOP.CALENDAR

تقويم النشر

يقرر متى وأين تُنشر الموجزات. توزيع منصات يحترم توجيهات التجنّب والتفضيل، بإيقاع متوازن لا يُغرق منصة ويُهمل أخرى. تقويم محتوى جارٍ، لا منشورات متفرقة.

LOOP.CREATIVE

الموجز الإبداعي

يحوّل الموجز المكتمل إلى أوامر توليد صور وفيديو مهيكلة. محايد تجاه المزوّدين — مرّر الأمر عبر أي أداة توليد تستخدمها أصلًا.

LOOP.LEADS

تأهيل العملاء المحتملين

يقيّم الواردين على محاور الميزانية/النية/الصلاحية، يصوغ تواصلًا شخصيًا، ويطلق تنبيهًا فوريًا عند أي فرصة ساخنة.

LOOP.CHASE

مطاردة الرسائل [CONTRACT DEFINED]

فرز صندوق الوارد عبر القنوات. عقد النطاق جاهز — ابنِ وحدتك عليه بالنمط ذاته المتبع في بقية الحلقات.

07 / INTEL

أجبنا قبل أن تسأل.

هل أحتاج Claude Code تحديدًا؟

لا. أربعة مسارات جاهزة: Claude Code (يقرأ CLAUDE.md/AGENTS.md مباشرة)، وCursor (ملف القواعد موصول سلفًا)، وChatGPT (دليل الإعداد مرفق)، أو مفتاح API خام عبر agent_shim.py دون أي وسيط. اختر ما تدفع ثمنه أصلًا.

هل بيانات عملائي آمنة عند إضافة عميل حقيقي؟

ملف .env وأسرار كل عميل مستثناة من Git تلقائيًا لكل عميل على حدة — ستحتاج أن تتعمّد الخطأ كي تكشفها. ولا وجود لأي رجوع صامت إلى بيانات اعتماد مشتركة، بقرار تصميمي مقصود.

هل سيظهر اسم وكالتي أم اسم المشغّل الأصلي؟

اسمك. OPERATOR_NAME يُضبط من الإعدادات — اضبطه مرة واحدة، وكل مُخرَج يتولد باسمك.

ماذا لو كان لديّ عميل واحد فقط الآن؟

لا يهم. البنية متعددة العملاء لا تكلفك شيئًا إضافيًا مع عميل واحد — وهي جاهزة سلفًا حين توقّع عميلك الثاني.

هل ينشر أو يرسل أي شيء تلقائيًا؟

أبدًا. مبدأ الصانع/المراجع تعاقدي في كل حلقة. المسوّدات تُكتب؛ وأنت توافق على كل ما يلمس العالم الخارجي.

هل توجد بيانات عملاء حقيقية في التوزيعة؟

لا. هذه توزيعة منقّاة — بيانات العملاء الخاصة وبيانات الاعتماد الفعلية لا تُضمّن أبدًا في النواة.
