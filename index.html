07 / Intel

Asked before you asked.

Do I need Claude Code specifically?

No. Four working paths: Claude Code (reads CLAUDE.md/AGENTS.md natively), Cursor (rules file already wired), ChatGPT (setup doc included), or a raw API key via agent_shim.py with no harness at all. Pick whichever you already pay for.

Is this just another Claude Code prompt pack?

No. The prompt packs on Gumroad selling for around $89 are markdown and agent-definition files under an MIT license — no backend, no memory, no scheduler. The Foundry is a Python engine with its own database, state, scheduler, and live Google Ads integration. The agent layer sits on top of it and can be swapped out entirely.

Isn't GoHighLevel or Vendasta cheaper?

Cheaper per month, more expensive over time. GoHighLevel's white-label reseller tier is $497/month, recurring, and they host it. Vendasta runs $99–$999/month plus a $500–$2,500 onboarding fee and per-seat costs. Both licenses here are one payment. You own the code and the client relationship either way.

Is my client data safe when I add a real client?

Each client's .env and secrets are gitignored per-tenant automatically — you'd have to go out of your way to accidentally commit one. No silent fallback to shared credentials, by deliberate design.

Will this show my agency's name or the original operator's?

Yours. OPERATOR_NAME is config-driven — set it once, every generated artifact uses it.

What if I only have one client right now?

Doesn't matter. Multi-tenant structure costs nothing extra at one client — and it's already there when you sign your second.

Does it auto-post or auto-send anything?

Never. Maker/checker is written into every loop's contract. Drafts get generated. You approve everything that touches the outside world.

Is real client data included?

No. This is a sanitized distribution — proprietary client data and active API credentials are never included in the core kernel.

Why pay $497 instead of hiring a developer to build this myself?

A developer builds you a version one. This is a version-forty-plus system that already ran a live ad account for a year — the state bugs, the race conditions, the "what happens when the API times out mid-loop" failures are already found and fixed. You're not buying code, you're buying the mistakes already made. A developer good enough to build this from scratch charges more than $497 for the discovery phase alone.

What happens when Claude, Cursor, or the underlying model changes?

Nothing that matters. The Python engine — state, scheduler, Google Ads pulls, Telegram alerts — never calls a model directly. It's deterministic and vendor-agnostic by design. The AI layer is a swappable module, not the foundation: four wired paths today, and a vendor change breaks one of those four, not the kernel.

I already have Claude Code. Why not build this myself for free?

You can. Budget forty-plus hours for state management, multi-tenant isolation, a real scheduler, live ad-account polling, and maker/checker contracts — then budget more time to find the bugs already fixed here. $497 buys back those 40 hours on client #1. Every client after that is the actual margin.
